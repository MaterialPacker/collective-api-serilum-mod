# Collective — Serilum Mod Library

[![Download Latest](https://img.shields.io/github/v/release/MaterialPacker/collective-api-serilum-mod?style=flat-square&label=Download&color=brightgreen)](https://github.com/MaterialPacker/collective-api-serilum-mod/releases/latest)
[![Forge](https://img.shields.io/badge/Loader-Forge-orange?style=flat-square)](https://files.minecraftforge.net/)

A shared library used by all of Serilum's mods, providing common code and config utilities.

![Collective — Serilum Mod Library Preview](https://cdn.modrinth.com/data/e0M1UDsY/f5e4fe9ac298e2c14591920d6bda937c566accd0_96.webp)

## Features

- Shared config handling across 100+ Serilum mods
- World and chunk event utility methods
- Player data and NBT helper abstractions
- Reduces total download size by sharing code
- Required by Compact Help Command, One Person Sleep, etc.

## Installation

1. Install [Minecraft Forge](https://files.minecraftforge.net/) for your Minecraft version
2. Download the JAR matching your exact Minecraft version above
3. Place the JAR into your `.minecraft/mods/` folder
4. Launch Minecraft with the Forge profile

## Requirements

- **Mod Loader:** Forge
- **Minecraft:** See download table above
